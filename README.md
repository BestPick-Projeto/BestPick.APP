# BestPick — Frontend | Desenvolvimento Autônomo

## Sobre o projeto

O **BestPick App** é a interface de uma aplicação de recomendação de produtos, desenvolvida para proporcionar uma experiência de busca interativa e intuitiva.

Esta versão foi desenvolvida de forma autônoma, sem auxílio de ferramentas de inteligência artificial na implementação das funcionalidades.

Durante o desenvolvimento, pude aplicar conhecimentos de programação frontend e enfrentar novos desafios relacionados à construção de interfaces, estilização e interação com o usuário.

## Principais desafios técnicos

### 1. Desenvolvimento da interface do chatbot

O maior desafio durante o desenvolvimento do frontend foi construir a interface do chatbot.

Até então, eu não havia trabalhado com componentes desse tipo, que precisam permitir o envio de mensagens pelo usuário e a exibição das respostas dentro de uma mesma interface.

A implementação exigiu compreender melhor como organizar os elementos da conversa, controlar a apresentação das mensagens e desenvolver um componente que funcionasse de maneira responsiva.

Por ser uma experiência nova, essa etapa exigiu bastante aprendizado e adaptação.

### 2. Estilização com HTML e CSS

Outro desafio significativo foi a estruturação e a estilização da interface utilizando HTML e CSS.

A principal dificuldade estava na variedade de abordagens disponíveis para construir componentes visuais, organizar elementos e definir estilos.

Foi necessário explorar diferentes possibilidades de estruturação e estilização para desenvolver uma interface organizada, visualmente consistente e adequada à proposta da aplicação.

### 3. Responsividade e organização dos componentes

A construção de uma interface responsiva também representou uma oportunidade importante de aprendizado.

O objetivo era organizar os elementos da aplicação de maneira que o chatbot e os demais componentes mantivessem uma apresentação adequada em diferentes tamanhos de tela.

Esse processo contribuiu para ampliar meus conhecimentos sobre organização visual, estruturação de componentes e desenvolvimento de interfaces.

## Principais aprendizados

O desenvolvimento do frontend do BestPick contribuiu para minha evolução em:

- Construção de interfaces de chat interativas.
- Organização e apresentação de mensagens.
- Estruturação de interfaces utilizando HTML.
- Estilização e personalização de componentes com CSS.
- Desenvolvimento de layouts responsivos.
- Resolução autônoma de problemas de frontend.

## Evolução do projeto

Esta versão representa o desenvolvimento do frontend do BestPick sem auxílio de inteligência artificial na implementação.

O projeto também possui uma versão desenvolvida com auxílio de IA, permitindo comparar as abordagens de desenvolvimento, os desafios enfrentados e os aprendizados obtidos em cada processo.
